# LiteCast source provenance

LiteCast derives from the user's `/gscratch/ark/graf/shardcast-0.3.2`
ShardCast snapshot, including HTTP/in-memory distribution, optional UCXX,
manifests and selective CPU-buffer transfer support developed in this task.
The Python distribution, import namespace, commands and environment variables
are named `litecast` / `LITECAST`. Upstream authorship and version metadata
are retained. Local bytecode and benchmark artifacts are not part of the snapshot.
